Model & Backend Processing Logic

💻 Data Encoding & Scaling

Categorical features (protocol_type, service, flag) are dynamically converted to numerical arrays using LabelEncoder. The entire 41-feature array is normalized via StandardScaler before being fed into the model to ensure uniform variance.

🗂️ Threat Mapping

The system maps over 35 distinct sub-attacks into core categories: Volumetric attacks (e.g., neptune, smurf) route to DoS, surveillance sweeps (e.g., nmap, ipsweep) to Probe, guessing passwords to R2L, and buffer overflows to U2R.

⚙️ Model Working

The preprocessed data is fed into the trained Random Forest Classifier. The model processes the input through an ensemble of decision trees, aggregates their individual predictions, and uses majority voting to classify the network traffic as Normal or a specific threat category.

📊 What the Confusion Matrix Tells Us

The Confusion Matrix visualizes the model's performance by comparing predicted attacks against actual attacks. It highlights exactly where the model excels (True Positives) and where it gets confused (False Positives/Negatives), which is especially useful for tracking how well it detects rare attacks like U2R.
