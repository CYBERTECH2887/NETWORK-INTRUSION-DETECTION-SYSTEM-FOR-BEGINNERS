Encoding and scaling

The text fields protocol_type, service and flag become numbers with LabelEncoder. All 41 features are then standardised with StandardScaler so the neural network trains evenly. Values never seen in training fall back to a default.

Attack grouping

More than 35 specific attacks are grouped into four families: DoS (for example neptune, smurf), Probe (nmap, portsweep), R2L (guess_passwd, warezclient) and U2R (buffer_overflow, rootkit).

How the two models vote

Both models output a probability for each class and the two are averaged. If the combined probability of all attack classes is above 40%, the most likely attack class is reported. Otherwise the traffic is labelled Normal. The lower threshold favours catching attacks over avoiding false alarms.
