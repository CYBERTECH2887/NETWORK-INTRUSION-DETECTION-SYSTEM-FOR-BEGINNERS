Project Overview

Objective

Enhancing network perimeter security by leveraging ensemble machine learning techniques on the NSL-KDD benchmark dataset to classify anomalies, prevent zero-day penetrations, and mitigate malicious network vectors in real-time.[cite: 6]

Scope

  • Multi-class categorization: Normal, DoS, Probe, U2R, and R2L.[cite: 6]
  • Live packet extraction and header transformation via Scapy.[cite: 6]
  • Feature standardisation and persistent ML model inference.[cite: 6]

Core System Modules

The architecture of this Intrusion Detection System is divided into four distinct phases, from data preparation to user interaction.

1. Data Preprocessing

Processes the raw NSL-KDD dataset to ensure high-quality training data. It maps over 35 specific sub-attacks into 5 core categories (Normal, DoS, Probe, U2R, R2L). Categorical features (protocol, service, flag) are transformed using LabelEncoder, and the 41-feature array is normalized via StandardScaler for optimal model accuracy.

2. Model Training & Evaluation

Trains robust Machine Learning algorithms, specifically Random Forest and Decision Tree classifiers. It utilizes class_weight='balanced' to handle the severe underrepresentation of stealthy attacks like U2R and R2L. Performance is evaluated using accuracy scores and confusion matrices before serializing the models via joblib.

3. Backend & Flask API

Acts as the central execution engine of the project. Built on Python Flask, it provides RESTful API endpoints for manual form predictions and batch CSV processing. Additionally, it integrates the Scapy library to actively intercept and inspect real-world network packets in real-time.

4. Frontend Interface

A responsive, dark-themed web dashboard designed for cybersecurity monitoring. It seamlessly connects with the Flask backend via JavaScript and offers three primary tools: a manual threat analysis form, a drag-and-drop batch CSV inspector, and a dynamic real-time network traffic log.
